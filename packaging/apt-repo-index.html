Penguin cpp

Un IDE de C y C++ sencillo para aprender, para Linux (Debian, Ubuntu, Linux Mint y derivadas, amd64) y macOS (Apple Silicon).

Instalar en Linux

Una sola vez, agrega el repositorio y su clave:

curl -fsSL https://juanfrang.github.io/Penguin-cpp/penguin-cpp.gpg | sudo tee /usr/share/keyrings/penguin-cpp.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/penguin-cpp.gpg] https://juanfrang.github.io/Penguin-cpp stable main" | sudo tee /etc/apt/sources.list.d/penguin-cpp.list
sudo apt update

Después se instala como cualquier programa:

sudo apt install penguin-cpp

Las versiones nuevas llegan con sudo apt upgrade.

Desinstalar

sudo apt remove penguin-cpp
sudo rm /etc/apt/sources.list.d/penguin-cpp.list /usr/share/keyrings/penguin-cpp.gpg

Instalar en macOS (Apple Silicon)

En Terminal, una línea instala la última versión en Aplicaciones (y la actualiza cuando la vuelves a ejecutar); si faltan las Command Line Tools de Apple (clang, make, lldb), macOS pide instalarlas:

curl -fsSL https://juanfrang.github.io/Penguin-cpp/install-macos.sh | bash

O descarga Penguin-cpp-…-arm64.dmg de la última versión y arrastra Penguin cpp a Aplicaciones. Así, como la app no está firmada por un desarrollador de Apple, la primera vez hay que abrirla, cerrar el aviso y pulsar Abrir igualmente en Configuración del Sistema > Privacidad y seguridad.

Reportar un problema

Escribe a jfgonzalez@unimagdalena.edu.co: el enlace abre tu correo con el asunto y el cuerpo listos para completar. Adjunta lo que ayude a ver el problema (desde esta página no se pueden agregar adjuntos; agrégalos en tu correo antes de enviarlo):

  • una captura de pantalla (en macOS ⇧⌘4 o ⇧⌘5; en Linux, la tecla Impr Pant);
  • penguin-cpp-errores.txt, el registro que Penguin cpp deja en tu Escritorio cuando tiene un error (si es corto, también puedes pegarlo al final del cuerpo);
  • el archivo .cpp o el proyecto con el que pasa, si puedes compartirlo.

Un ejemplo. Asunto:

[Penguin cpp 0.2.0] El depurador no se detiene en el punto de parada (macOS)

Cuerpo:

Hola,

Versión de Penguin cpp: 0.2.0
Sistema: macOS 15 en un Mac M1
Cómo lo instalé: instalador de una línea

Qué hice:
1. Abrí prueba_depurador.cpp
2. Puse un punto de parada en la línea 20
3. Ejecutar > Depurar

Qué esperaba: que se detuviera en la línea 20.
Qué pasó: el programa terminó sin detenerse y el panel de depuración mostró
"The program ended with exit code 0."

Adjunto la captura de pantalla, penguin-cpp-errores.txt y prueba_depurador.cpp.

Gracias.
